# 🎓 منصة مُجاوِب (Mojaweb) — المساعد الدراسي والجامعي الذكي

> تطبيق ومساعد دراسي ويب متكامل يدعم تحليل المستندات والكتب والتسجيلات الصوتية والمرئية، وتوليد الاختبارات التفاعلية والملخصات الفورية، بالاعتماد على تقنية **RAG المقيدة بنسبة 100%**.

---

## 🌟 الميزات والإمكانيات الجديدة

1. **دعم المستندات والصوتيات والفيديوهات (Multi-Modal Ingestion)**:
   - مستندات: `PDF`, `DOCX`, `PPTX`, `XLSX`, `CSV`, `TXT`, `MD`.
   - صوتيات وفيديوهات: `MP3`, `WAV`, `M4A`, `OGG`, `AAC`, `MP4`, `MOV`, `WEBM`.
   - تفريغ الكلام الصوتي وتقسيمه لمقاطع زمنية موثقة لتسهيل البحث والاستشهاد بالدقيقة والثانية.
   - الحد الأقصى للحزمة: **50 ميجابايت (50MB)**.

2. **نظام الاختبارات التفاعلية الذكي (Interactive Quiz Generator)**:
   - توليد اختبارات تقييمية ذكية (5، 10، 15 سؤالاً) من محتوى الملفات.
   - دعم أسئلة اختيار من متعدد (MCQ) وصح أو خطأ.
   - تجربة حل تفاعلية مع تصحيح فوري، واحتساب النسبة المئوية، وشرح تفصيلي لكل إجابة مع ذكر المصدر الموثق.

3. **التلخيص الذكي لأهم النقاط (Smart Summary)**:
   - استخلاص المفاهيم والمحاور الأكاديمية بنقرة زر واحدة.
   - دعم تصدير ونسخ الملخص بصيغة Markdown منسقة.

4. **المحادثة المقيدة الصارمة (Strict RAG Chat)**:
   - استرجاع دلالي ومعجمي فوري (BM25 + TF-IDF) داخل الذاكرة المؤقتة.
   - توثيق دقيق للمصادر يوضح اسم الملف ورقم الصفحة/الشريحة أو التوقيت الزمني.
   - **قاعدة الرفض الصارم**: الرد المعياري الحرفي عند ورود أي سؤال خارج سياق الملفات:
     > *"عذراً، هذا السؤال خارج سياق الملفات المرفوعة، ولا يمكنني الإجابة إلا بناءً على محتواها."*

5. **هوية بصرية معتمدة (Color Hunt Theme)**:
   - لوحة الألوان المعتمدة: `#FDF4D2` (كريمي)، `#B0CDE6` (سماوي)، `#A290B7` (لافندر)، `#946D6D` (ماروني).
   - دمج الشعار الرسمي لمنصة "مُجاوِب".

6. **جاهز للنشر على Render (Render Web Service)**:
   - استماع ديناميكي على `0.0.0.0` ومنفذ `$PORT`.
   - قراءة سرية للمفتاح `OPENROUTER_API_KEY` من متغيرات البيئة.

---

## 👨‍💻 المطور
تمت برمجة وتطوير منصة **مُجاوِب** بالكامل بواسطة: **محمد تركستاني**

---

## 🚀 التشغيل المحلي (Local Setup)

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
افتح المتصفح وتوجه إلى: `http://localhost:8000`

---

## ☁️ النشر على Render (Render Deployment)

- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
- **Environment Variables**:
  - `OPENROUTER_API_KEY`: مفتاحك من OpenRouter.
